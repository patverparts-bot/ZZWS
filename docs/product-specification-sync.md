# Обновление характеристик товаров

## Требование владельца от 4 ноября 2026 года

Обновление запускается вручную кнопкой в админке. Ежедневное расписание отменено владельцем до его создания. Текущий источник — публичные карточки товаров zigzag.am. Сайт использует сохранённые проверенные характеристики, включая срок гарантии.

При переезде на корпоративный сервер источник необходимо заменить синхронизацией с 1С: по сообщению владельца, zigzag.am получает эти сведения из 1С. Доступ к 1С, её конфигурация и формат обмена ещё не предоставлены; подключение к 1С сейчас не реализуется.

## Граница источника данных

- Интерфейс запускает обновление характеристик и показывает настоящий ход задания. Название функции и хранилище не должны зависеть от zigzag.am.
- Адаптер источника получает сохранённые идентификаторы товаров и возвращает подтверждённые характеристики с идентификатором источника и временем проверки. Сейчас используется адаптер `zigzag`; в будущем его заменяет адаптер `onec` (1С).
- Управление заданием, возобновление, права доступа, сохранение результата и показ характеристик/гарантии используют общий контракт и не требуют замены при смене адаптера.
- Текущий адаптер проверяет точное совпадение артикула и модели. Успешный ответ заменяет набор фактов, включая изменённые/удалённые значения и гарантию `0`. При ошибке сохраняются прежние сведения и прежнее время проверки.
- Цены, остатки, заказы, получатели отчётов и фотографии этой функцией не изменяются.

## Что уточнить при переходе на 1С

Сопоставить стабильный идентификатор номенклатуры 1С с артикулом каталога, варианты/характеристики номенклатуры, единицы измерения и срок гарантии. Определить полномочный источник, формат API/обмена, способ авторизации и обработку удаления/пустых значений. Учётные данные хранятся только на корпоративном сервере. До включения нового адаптера сверить контрольную выборку и проверить, что изменённые факты доходят до карточек, увеличенного фото и помощника.

При замене адаптера также настроить разрешённое происхождение данных для `knowledgeProduct` и отображения ссылки источника в техническом окне: текущие проверки разрешают только zigzag.am. Открытые задания прежнего источника завершить или остановить до переключения. Нативный Android пока читает отдельные статические JSON с кэшем 24 часа; использование нового сохранённого API нужно согласовать с отдельным выпуском приложения, не менять уже опубликованный подписанный APK.
