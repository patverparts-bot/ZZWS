# Catalog table width and wholesale price review

Table view uses the available window width; card view retains its existing layout. `js/catalog-table-width.js` derives column widths from the authorized header keys, including reseller and admin price/margin fields. The table minimum width is the sum of visible columns. Hidden columns remove their widths and do not misalign the body. Unknown future columns receive a separate default width.

When the table fits, page scrolling and its existing sticky heading behavior continue. When it does not fit, its region scrolls horizontally and vertically with a 75dvh height limit, sticky headings/category labels and keyboard focus. Scrolling near its bottom uses the existing guarded batch loader. The document itself does not overflow horizontally. Width changes, role changes and column preferences recompute the layout. `catalog-columns.js` notifies the width helper after hiding columns. Prices, permissions and cart data are unchanged.

The list picker is available only in the catalog. Its scripts and session hooks have been removed from the administrative price-update page, as requested. The picker implementation assets remain under `admin/` but the management dashboard does not mount them.

The price-update detail list now includes existing products with actual changes to `ws`, `kp` or `kpPromo`. Retail/base-only changes, stock-only changes, additions and removals do not appear in this focused list. The existing overall import counts, raw-price warnings, publication confirmation and import payload remain authoritative and unchanged.

For truncated previews, the browser reads the existing authenticated full-report endpoint and filters the complete data before limiting the on-screen list to 300 products. A cached full report is reused for export. Session changes and a new preview invalidate in-flight report rendering. Fetch errors can be retried using the export button. There is no backend or schema change.

The old CSV download button is replaced with a readable `Wholesale-price-changes.xlsx`: a title, counts, a note explaining zero/missing prices, and columns Article, Model, Price type, Before, After, Difference AMD, Difference %. One row describes one changed wholesale price; source labels are WS (Dealer), KP and KP Promo. Codes preserve leading zeros, prices/differences/percentages are numeric, and percentages are blank when the previous price was zero. Column widths, number formats and an autofilter support reading and filtering. Labels follow Armenian/Russian UI localization. The complete wholesale report is exported, not only the first 300 preview products.

Validation: `tests/ui/catalog-table-width.cjs` covers standard/reseller/admin/admin+reseller column sets, three desktop widths, hidden-column alignment, native scrolling, loading past 40 products and mobile cards. `catalog-sticky-header.cjs` checks both page-sticky and native table-sticky modes in Armenian/Russian. `wholesale-price-review.cjs` checks retail exclusion, filtering the full report beyond 300 retail changes, all wholesale sources, numeric Excel output, leading zeros and stale/empty previews. All API data in browser checks is synthetic; no real imports or orders are published by tests.
