# Категории, аналоги и обратная связь

## Порядок подбора

1. Распознать семейство по категории каталога. Название модели само по себе не определяет категорию. У аксессуаров отдельный класс.
2. Проверить подтип и назначение. Духовка не заменяется микроволновкой; морозильник — холодильником; обычный утюг — парогенератором. Газовая, электрическая и индукционная панели разделены. Автоматическая, капсульная, рожковая и капельная кофемашины разделены; для аналогов капсульных моделей проверяется система капсул. Пылесосы разделены на обычные, беспроводные, ручные, моющие, роботы, промышленные и бассейновые.
3. Сохранить обязательные условия: установка, подключение, фронтальная/вертикальная загрузка, наличие сушки и подтверждённые необходимые функции. Для холодильника нельзя потерять No Frost, для телевизора — подтверждённую частоту обновления или разрешение. Известные типы крепления и схемы конфорок сохраняются. Аксессуары и неизвестные категории не становятся аналогами техники.
4. При запросе аналога определить конкретную исходную модель. Проверить её доступность в текущем каталоге либо в проверенном публичном справочнике. Не использовать старую модель вместо нового неизвестного артикула.
5. Сравнить подтверждённые основные числовые параметры в пределах своей категории. Указанные пользователем `до`, `от`, точный размер, бюджет и функции остаются обязательными. Все отклонения показываются в карточках вместе с исходным значением, фактическим значением и единицей.
6. Отсортировать прошедшие ограничения товары по технической близости; затем по выбранному приоритету и цене. Низкая цена не компенсирует другой тип товара.

Если критичные сведения исходной модели или кандидата неизвестны, помощник не подтверждает взаимозаменяемость. Для неизвестных исходных параметров предлагается другая исходная модель либо обычный подбор по явным требованиям. Для неоднозначного запроса кофемашины/пылесоса уточняется подтип, для варочной панели — принцип работы.

## Начальные поисковые границы аналогов

Это настраиваемые эвристики поиска, а не допуски монтажа или гарантия взаимозаменяемости.

| Семейство | Основные числовые параметры | Габариты отдельно стоящего устройства |
|---|---|---|
| Стиральная машина | Загрузка ±1 кг; отжим ±200 об/мин, если подтверждён | Ширина ±1, высота ±2, глубина ±3 см |
| Сушильная машина | Загрузка ±1 кг | Ширина ±1, высота ±2, глубина ±3 см |
| Холодильник / морозильник | Объём ±15% | Ширина ±5, высота ±10, глубина ±5 см |
| Посудомоечная машина | Вместимость ±2 комплекта | Ширина ±1, высота ±2, глубина ±3 см |
| Телевизор | Диагональ в пределах меньшего из ±10% и ±5 дюймов | Основной показатель — диагональ; явные ограничения размеров сохраняются |
| Духовка | Объём ±15% | Для встраиваемой — отдельная проверка ниши |
| Микроволновка | Объём ±20% | Ширина/глубина ±3, высота ±2 см |
| Варочная панель | То же подключение, количество и подтверждённая схема конфорок | Вырез / ниша проверяется отдельно |
| Кофемашина | Тот же подтип и совместимая подтверждённая система капсул; объём ±20%, если известен | Ширина ±3, высота/глубина ±5 см |
| Пылесос | Тот же подтип; всасывание в Па ±20%, если известно; сохранение моющей функции | Разные подтипы не смешиваются по габаритам |
| Ноутбук | Подтверждённый тот же процессор, без снижения ОЗУ/накопителя; экран ±1 дюйм | Неизвестный процессор не заменяется догадкой о производительности |

Без явно указанного бюджета аналог с подтверждённой ценой ограничен диапазоном ±20% от исходной цены. Публичная модель без цены остаётся отдельной справочной рекомендацией с неподтверждённым соответствием бюджету.

Для встраиваемых моделей габариты корпуса, упаковки и размеры ниши извлекаются отдельно. Для аналога требуются подтверждённые совпадающие размеры ниши; сантиметровый поисковый допуск не применяется к вырезам. Диапазон вроде `177.2–178` не подменяется одной точкой. Крепление фасада, вентиляция и подключение требуют проверки инструкции конкретной модели. Такая проверка соответствует отдельным требованиям производителя к [точной нише холодильника](https://www.bosch-home.com.sg/experience-bosch/kitchen-installation-guide/fridge-installation-installation) и [установке индукционной панели](https://www.bosch-home.co.uk/en/c/spotlight/blt653d369478286102/customer-service/get-support/installation-hub/fitting-an-induction-hobs).

## Как действуют отметки владельца

- «Неправильно» создаёт активное правило. При выборе конкретных неверных карточек исключаются только они. Без выбора карточек отклоняется вся показанная подборка для тех же распознанных условий.
- Для неправильной категории, подтипа или требования владелец пишет **правильный запрос**, например «капсульная кофемашина Nespresso» или «встраиваемый холодильник». Исходный бюджет сохраняется. Комментарий используется для объяснения, а не как исполняемая инструкция.
- Правило запроса привязано к каноническим условиям: категория, подтип, бюджет, размеры, функции, исходная модель и т. п. Поэтому «холодильник до 200 тысяч» и «подбери холодильник, бюджет 200000 драм» получают одно исправление. Другой бюджет или другие ограничения не наследуют исключения произвольно.
- Причина «Слишком далёкий аналог» сужает числовые отклонения до одинаковых значений. Отдельный флажок распространяет это требование на аналоги всей категории. Он не переписывает запросы других категорий.
- «Верно» / «Не проверено» отменяет правило данной отметки. Остальные действующие отметки сохраняются. Две конкурирующие правки не перезаписываются молча.
- Вопросы, ответы и характеристики остаются неизменяемыми снимками. Правило и оценка меняются атомарно. Только владелец может создавать правила. Цены и доступность каждого ответа по-прежнему берутся из текущего разрешённого пользователю каталога.
- Это прикладная обучаемая память, а не обещание полного понимания произвольной фразы или переобучение весов внешней модели. Неизвестное пожелание требует уточнения.

Код: `appliance-taxonomy.mjs`, `assistant-similarity.mjs`, `assistant-learning.mjs`. Публичный индекс строится из той же таксономии командой `node scripts/build-assistant-taxonomy.mjs`; цены, остатки и клиентские правила в индекс не входят.
